### <a name="_3bfxc9a45514"></a>**Функциональные требования**
|**№**|**Действующие лица или системы**|**Use Case**|**Описание**|
| 1 | Сотрудники кол-центра| Консультация клиента | Нужно, чтобы сотрудники кол-центра могли проконсультировать клиентов хотя бы по текущим ставкам банка |
| 2 | Партнёрский кол-центр| Консультация клиента |важно, чтобы сотрудники партнёрского кол-центра также могли проконсультировать клиентов по актуальным депозитным ставкамо |
| 3 | Клиент| Получение информации | Клиент может уточнить условия открытия депозита по телефону |

### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**
|**№**|**Требование**|
| 1 | Используем  партнерский колл-центр |
| 2 | Предоставляем актальную информацию по ставкам по депозитам для партнерского центра |
| 3 | Предоставляем актальную информацию по ставкам по депозитам для своего кол центра |


### <a name="_qmphm5d6rvi3"></a>**Решение**
Диаграммы в этой же папке

Сервис АБС предоставляет кол-центру информацию по актуальным депозитным ставкам.
Колл-центр предоставляет информацию своим операторам и состовляет и отправляет файл парнерам

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

- Разработать робота для стандртных паттернов.
- Система онбординга для пожелых клиентов

**Недостатки, ограничения, риски**

- Риск высокой нагрузки на собственный кол центр
- Кол-центр партнёра работает во внешней информационной системе относительно банка. Они готовы получать актуальные ставки в виде файлов. Нет возможности сделать API-вызовы (например, через SFTP-протокол).
